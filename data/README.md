# Experimental Data

This directory contains the small controlled dataset used for the preliminary experiment.

## Required files

- `p232_001.wav` — clean speech utterance from the VoiceBank test set
- `ch01.wav` — channel 1 of the DEMAND PCAFETER cafeteria-noise recording
  
All signals are processed as mono 16 kHz audio.

The initial hub experiment uses only one clean utterance and one café-noise recording at:

- 10 dB SNR
- 5 dB SNR
- 0 dB SNR

The full dataset is not stored in this repository.

## Full classical experiment

Place the 40 clean VoiceBank WAVs listed in the archived
[full results](../results/full_experiment/full_metrics.csv) in `data/clean/`.
Use the unique values in the `Clean_File` column so the filename order
and generated white-noise sequence match the original run.

Place the DEMAND cafeteria and traffic channels at `data/noise/cafe.wav`
and `data/noise/traff.wav`. See the repository's Resources section for the
dataset links. White noise is generated by the script with seed 5305.

From the repository root, `python experiments/full_experiment.py` writes a
new full CSV. Use a separate copy when comparing against the archived
submission. The bundled example runs independently with
`python experiments/demo.py`.

For a fresh MP-SENet run, put the
[upstream implementation](https://github.com/yxlu-0102/MP-SENet) in
`external/MP-SENet/`, install its dependencies, and place the VoiceBank
checkpoint at `external/MP-SENet/best_ckpt/g_best_vb`. Then run:

```sh
PYTHONPATH=. python experiments/generate_mpsenet_inputs.py
python experiments/run_mpsenet_batches.py
python experiments/evaluate_mpsenet.py
python experiments/compare_matched_results.py
python experiments/analyze_final_results.py
```

The repository contains the prior batch's CSVs for reproducing the published
analysis without running the model. A fresh run can process a different
number of mixtures depending on where inference finishes.
