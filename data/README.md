# Experimental Data

This directory contains the small controlled dataset used for the preliminary experiment.

## Required files

- `p232_001.wav` — clean speech utterance from the VoiceBank test set
- `ch01.wav` — channel 1 of the DEMAND PCAFETER cafeteria-noise recording
  
All signals are processed as mono 16 kHz audio.

The initial hub experiment uses only one clean utterance and one café-noise recording at:

- 10 dB SNR
- 5 dB SNR
- 0 dB SNR

The full dataset is not stored in this repository.

## Full classical experiment

Place the 40 clean VoiceBank WAVs listed in the archived
[full results](../results/full_experiment/full_metrics.csv) in `data/clean/`.
Use the unique values in the `Clean_File` column so the filename order
and generated white-noise sequence match the original run.

Use the 16 kHz files from [DEMAND](https://zenodo.org/records/1227121).
Rename `PCAFETER/ch01.wav` to `data/noise/cafe.wav` and
`STRAFFIC/ch01.wav` to `data/noise/traff.wav`. The repository's
`data/ch01.wav` is byte-identical to the cafeteria input. White noise is
generated by the script with seed 5305. The clean files are from the
[VoiceBank test archive](https://datashare.ed.ac.uk/handle/10283/1942).

## Archived input and matched-set checks

The preserved experiment workspace contained 360 manifest rows and 360
mono 16 kHz PCM16 input WAVs. It also contained 167 enhanced WAVs. All 167
output filenames matched the `Enhanced_File` column of the public
[MP-SENet score table](../results/mpsenet/mpsenet_metrics.csv), and the
score table was byte-identical to the copy in the experiment workspace.
Use that column to select the historical matched subset. A fresh batch
may finish a different subset.

The largest absolute PCM16 sample in the original input WAVs was 25,992
out of 32,768 (about 0.793 of full scale), both across all 360 inputs
and in the 167 matched inputs. None contained samples at either PCM16
endpoint. A separate reconstruction from the official clean test archive
and the two verified noise files found zero pre-write samples outside
the PCM16 range. The reconstructed WAV set and archived WAV set had
different aggregate byte hashes. These checks cover input amplitude and
membership. Exact byte reproduction requires the original generation
environment.
